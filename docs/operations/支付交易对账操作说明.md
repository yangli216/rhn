# 支付交易对账操作说明

本期入口为“收费管理 → 支付对账”。它核对支付宝/微信交易账单与机构收退款事实，不证明商户余额或银行到账。

## 配置与授权

部署代码及配套公共/Oracle `V1_129_24__payment_transaction_reconciliation.sql` 增量迁移，保留既有收退费、支付配置和历史对账数据。迁移注册新的表、权限、角色及菜单，不给任何现有账号自动授权；需按职责分配机构财务角色。服务器沿用支付配置的密文服务，未提供加密能力时不能保存原始账单。

| 角色 | 用途 |
| --- | --- |
| `PAYMENT_RECON_ADMIN` | 当前机构查看、手工拉取/重试、策略维护、差异核查、复核、结案和机构明细导出 |
| `PAYMENT_RECON_MERCHANT` | 以上能力及商户全账/待归属查看；完整商户内容额外要求租户范围数据授权 |
| `PAYMENT_RECON_IMPORT` | 兼容历史标准化账单的受控导入；不赋予新账单核查或商户全账读取权限 |

角色组合允许按查看/执行/处理/复核/导出权限拆分职责。例外提交人不能复核自己的记录。工作机构必须明确，机构结果只显示原指令所属机构；共用商户不等于所有机构可以看其他机构流水。

“系统设置 → 支付渠道”先保存当前机构商户及安全凭证，再打开“对账策略”。策略按所选机构保存，不因管理员当前工作机构不同而写错机构。支付宝默认建议不早于北京时间 09:00、微信不早于 10:00；初始自动策略关闭、首次时刻 11:00、补拉 7 天。补拉范围最多 90 天，手动历史窗口按渠道能力限制。停用新收款独立于自动对账，历史查询和退款凭证继续复用。

## 核对与处置

1. 选择渠道和账单日期，点击“拉取并核对”；服务端创建持久化任务，页面查看排队、执行、待出账、重试或失败。不同机构共用商户时复用商户账期任务。
2. 成功发布后查看本机构双边明细及核对版本。渠道收款原额、已受理退款、完成退款、手续费分别展示，不用净额猜测单笔支付金额。
3. 本地未入账/状态差异可“查询原单并尝试恢复”；只查询可信的原指令，在途结果沿用原支付事务。不会重新扫付款码或新建退款；成功恢复后重新拉取核对以发布新快照。
4. 不能自动修正的差异填写依据，交由另一名财务人员接受例外或退回。接受例外不修改资金事实、不把差异变成对平。未处置或待复核记录存在时不能结案；带例外结案保留原差异结果。
5. 账单重跑产生新证据/新快照时保留旧版本。原始内容和本地事实均相同则不增加核对版本；每次拉取尝试仍留痕。历史、已结案或当前任务未成功的版本不能继续处置。
6. 商户待归属包括其他系统订单、未知原指令、院外流水，不得随意关联患者。商户财务人员填写例外并独立复核；机构“对平”与商户全账归属完成分开显示。

## 失败、证据与限制

未出账/账单不存在不是零交易；重试保留旧结果，失败不发布空白对平结果。支付宝仅已验签的明确无数据响应可发布空账，未签名错误仍等待取证。微信退款账单状态在出账后不会更新，PROCESSING/CHANGE/FAIL 需核查原退款状态。

下载文件先加密保存，解压/格式/汇总失败保留未发布证据及安全错误说明。只有额外商户范围授权可导出原账单；机构导出限制为本机构结果。导出操作均留痕。原始文件含第三方账号信息，不出现在普通 API 响应或日志中。

第一期只支持 CNY；单次原始或解压后文件合计最多 16 MiB、10 万行，ZIP 最多 8 文件，超限整体失败。支付宝支持中文标准明细及配套汇总/明确汇总尾行；微信支持 V2 新版 ALL，旧版“总金额/企业红包”格式会明确失败。未知格式不能通过人工解释绕过校验，应增加有版本的解析器和样本测试。

当前对账任务由后台定时器领取，租约 300 秒、自动重试最多 8 次；身份变更和权限错误需要处理配置后手工重试。部署级紧急停用可设置 `rhn.billing.reconciliation.worker-enabled=false`；机构日常启停用策略管理。失败在任务/策略页展示；外部消息通知、账单人工上传、自动证据销毁和资金/银行到账核验不属于本期交付。

## 发布验收

自动化验证使用隔离 H2 与假渠道，不能替代真实账单联调。正式发布前应验证：双方商户账单权限、中文下载格式、部分/跨日退款与优惠样本、Oracle 增量迁移、两人复核与机构数据隔离，以及 1280/1440/1920 页面视觉。执行任何环境更新前记录服务版本、备份与迁移计划；不在测试流程里操作现有业务库。

新增渠道实现 `ReconciliationAdapter` 的能力、商户范围、下载及规范解析，声明与支付注册表相同的提供者编码，补充字典和协议/契约样本即可复用页面及核心流程。新增账单语义（如资金账单）需要显式扩展通用契约。
