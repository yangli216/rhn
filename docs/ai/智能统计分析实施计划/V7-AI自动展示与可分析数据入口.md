# V7：AI 自动展示与可分析数据入口

日期：2026-09-15。状态：本地实现、专项测试、真实 AI / Oracle 和浏览器验证通过，未 commit / push。

## 本轮功能

1. 展示形式新增默认选中的“AI 自动识别”。用户只描述业务需求，AI 可选用现有五种模板，或生成指标卡 / 柱状图 / 趋势图 / 表格的组合页面。
2. 组合页面的区块顺序、区块标题、引用指标随最终定义保存；重新登录打开后仍是同一展示。不是仅在原五个按钮中自动挑选。
3. “可分析数据”移到业务需求标题栏右上角，在澄清对话中持续可见。进入编辑工作台后，顶部操作栏也保留入口；点击说明窗口查看四个数据来源、字段、分组及基础口径。
4. 连续修改携带当前组合方案。手动删除指标会同步清理、重编号区块引用；新增指标自动补充展示，避免保存后引用失效。
5. 变更对照包含展示形式和展示组合变化。

## 边界

- AUTO 是生成选择，不是可执行模板；查询和保存必须得到具体模板或 CUSTOM 组合定义。
- 组合页面最多 8 个区块、4 个指标，共享日期、范围及分组；指标可在多个区块复用。趋势图只使用按日/月分组。
- 任意 HTML / 脚本、自定义交互、地图、桑基图等不在本轮能力内；不能用自动展示补足医生维度、接诊时长等尚未接入的数据。
- 原有固化功能与预设模板继续可用，旧定义不要求 widgets 字段。各来源和费用口径继续沿用 V4/V5 限制。
