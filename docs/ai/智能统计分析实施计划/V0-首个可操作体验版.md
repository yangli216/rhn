# V0：首个可操作体验版

日期：2026-09-14。分支：`codex/analytics-a01`。

按用户最新优先级，不再逐项等待 A07–A18 的完整治理交付，先贯通可操作的门诊分析体验。用户明确选择**当前本地业务数据**。安全治理与审计深化延后，保留已有登录、工作上下文和租户/科室边界。

## 直接体验

- 页面：<http://localhost:15176/analytics>。使用现有本地账号登录后，点击左侧“智能统计分析”。
- 体验后端：<http://localhost:18086/actuator/health>，`oracle-local`，连接当前本地环境原有 Oracle 配置。
- 原有 8080 / 5173 服务保持运行；新体验使用独立端口。
- 已为当前 `doctor` 账号保存“近30天门诊挂号趋势”，可从“我的分析”载入后重新查询。

建议先做以下操作：

1. 点击“最近30天按日看挂号趋势”，检查右侧条件，再点“生成分析”。
2. 切换柱状图、折线图、数据表；点击图中数据点，查看对应分组的挂号、退号、诊毕数。
3. 试试“本月各科室诊毕人次”，查看当前机构内可访问科室；也可以直接调整指标、日期、分组、范围。
4. 修改分析名称，点击“保存分析”；重新登录后从“我的分析”载入并重新生成结果。
5. 配置修改可撤销。修改条件后旧结果会明确标注；纯图表切换不重新取数。

## 已交付能力

| 能力 | 实现 |
| --- | --- |
| 本地业务查询 | 门诊模块提供固定聚合端口；analytics 不访问临床模块内部类 |
| 指标 | 挂号人次、挂号队列退号人次、诊毕人次、挂号队列退号率 |
| 分组 | 按日、按月、按科室；日期分组补零，但不补入虚构业务数据 |
| 范围 | 当前科室，或当前机构内账号已有工作权限的科室；服务端解析，不接受任意科室 ID |
| 日期 | 固定开始/结束日期；近 7/30/90 天、本月、上月、今年；单次 1–366 天 |
| 比较 | 前一个连续等长时段；完整自然月区间使用此前完整自然月区间。结果明确显示比较日期；比较基数为零不计算增幅 |
| 可视化 | 三栏 PC 工作台、四项指标卡、可点选柱/折线图、数据表、描述性观察、取数时间和口径 |
| 需求整理 | 明确标注的**本地规则解析**，支持已列指标、日期、分组和图形修改；暂不支持的口径会反馈，不调用大模型或生成 SQL |
| 个人保存 | Oracle 中保存查询定义、名称和图形；按租户/所有者读取最近 50 份。每次保存新增快照，日期目前固定，不自动滚动 |

挂号以 `RHN_SC_PAT_REG.DT_REGISTERED` 为依据，包含转科新建挂号。退号计所选日期挂号队列截至查询时的取消状态，不代表期间发生的退号事件。诊毕以 `RHN_VIS_ENC.DT_COMPLETED` 及真实 `COMPLETED` 状态为依据，仅门诊，排除转科/终止。退号率合计按总分子/总分母重算；分母为零显示 0%，界面口径明确说明。

## 实现位置与边界

- `backend/.../outpatient/api/OutpatientAnalyticsDirectory.java`：公开日聚合数据契约。
- `backend/.../outpatient/reporting/OutpatientAnalyticsAdapter.java`：固定、参数绑定的门诊读取；每个事实查询最多读取 50,000 条，超过上限报错，不返回截断汇总。
- `backend/.../analytics/api/PilotAnalysis.java`：独立的 `outpatient pilot` DTO，不冒充完整 A04 AnalysisSpec。
- `backend/.../analytics/application/PilotAnalysisService.java`：工作范围、日期/比较期、聚合、口径与个人定义存取。
- `backend/.../analytics/web/PilotAnalysisController.java`：`/api/analytics/pilot/query`、`/saved`。
- `frontend/src/features/analytics/PilotWorkspace.tsx` 与 `pilot-workspace.css`：操作工作台。
- `pilotModel.ts`：当前本地规则与日期快捷项；UI 明确提示确认后执行。
- `docs/api/openapi.json` 与 `frontend/src/shared/api/generated.ts`：本轮新增 analytics 契约与生成类型。保留其他模块已有快照差异，不声称全仓契约已同步。
- `scripts/run-analytics-preview.sh`：常驻 Oracle 体验后端；独立实例标识与 Snowflake worker，关闭此实例的 outbox 调度。

开关为 `RHN_ANALYTICS_PILOT_ENABLED=true`（实际体验查询）和 `VITE_ANALYTICS_ENABLED=true`（前端入口），默认部署仍关闭。仅打开普通 `RHN_ANALYTICS_ENABLED` 不会开放查询。

数据库采用当前 Flyway 基线初始化，增量演进规则见数据库基线说明。

该版本不是 A07–A18 全量完成：正式目录审批、统计专用授权、独立只读连接池、异步运行/取消、完整必要审计、聚合隐私、模型/语音、共享/导出和发布治理未接通。当前查询使用业务连接池和同步固定读取；保留为本地体验环境，不将此版本当作正式上线验收。

## 启停与后续

当前体验服务已启动，无需用户再执行命令。需要重启时，在仓库根目录使用现有 Oracle 配置路径：

```sh
RHN_ORACLE_ENV_FILE=/path/to/.env.oracle.local bash scripts/run-analytics-preview.sh
```

另一个终端进入 frontend：

```sh
VITE_ANALYTICS_ENABLED=true RHN_API_TARGET=http://localhost:18086 npm run dev -- --port 15176 --strictPort
```

只管理所启动的预览实例，不停止 8080 / 5173 的既有服务。下一轮可直接依据实际体验反馈调整指标/交互，再接真实模型理解与正式语义目录；安全、审计深化按用户后续优先级恢复。未 commit / push。
