# V1：真实 AI 需求解析

2026-09-14，在 V0 的真实业务查询工作台上接入模型。V0 文档记录当时的本地规则实现；当前页面已改用服务端真实 AI 解析。

## 体验方式

访问 http://localhost:15176/analytics，使用现有开发账号登录。页面左侧显示当前模型配置状态，当前环境使用 `qwen3.8-27b`。

1. 输入“这个月各个科室完成接诊的情况，想用柱形图比较一下”。
2. 点击“AI 整理分析条件”，等待 AI 回复。AI 返回条件后更新右侧配置，但不立即查询。
3. 核对日期、指标、分组和范围，点击“生成分析”查询现有业务库。
4. 输入“查看本月诊断数量排行”，应明确提示该指标尚未接入，原条件保持不变。

## 边界

- 真实调用现有“AI助理配置”中的模型服务，复用租户配置和机构/科室启用范围。不修改现有模型配置。
- 发给模型的是用户需求、当前查询条件、机构时区下的今天日期及指标契约，不发送患者明细或查询结果。
- 模型只返回结构化建议，不直接访问数据库或生成可执行 SQL。服务端校验枚举、日期和结果状态，实际查询仍受现有工作科室权限约束。
- 支持挂号、挂号队列退号、诊毕人次与退号率，按日/月/科室分组。诊断数量、疾病排行、收入、医生分组和排序能力本轮未扩展。
- 服务不可用、超时、解析异常和需要澄清均明确反馈，不静默降级为关键词匹配。手动条件配置仍可用。
- 等待期间如果用户修改输入或条件，旧 AI 响应不会覆盖新条件。
