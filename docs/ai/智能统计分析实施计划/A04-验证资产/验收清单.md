## 状态、权限和并发守卫（规格，未执行）

| 编号 | 条件 | 应满足行为 |
| --- | --- | --- |
| G01 | 已发布 v1，提交新 v2 审核 | v1 继续可运行；v2 为 IN_REVIEW；发布指针仍指 v1 |
| G02 | v2 审核通过且 assetRevision 匹配 | 原子发布 v2 并移动指针；v1 内容不变 |
| G03 | v2 审核期间作者修改草稿 | 新建草稿版本；不覆盖审核快照；原审核只适用所提交版本 |
| G04 | 已发布版本被请求原地改 QuerySpec | 409 ANALYTICS_VERSION_IMMUTABLE |
| G05 | 两个请求同 baseDraftVersion 并发修改 | 一个成功创建新版本，另一个 409 ANALYTICS_DRAFT_VERSION_CONFLICT |
| G06 | 旧 run 返回而当前草稿已变更 | 保留历史记录；不覆盖当前预览 |
| G07 | 相同用户/上下文/operation 幂等键，相同请求重试 | 重新鉴权后返回同一资源 ID，不创建第二个任务 |
| G08 | 相同幂等键但 payload 不同 | 409 IDEMPOTENCY_KEY_REUSED |
| G09 | 别的用户使用相同幂等键 | 独立命名空间，绝不能重放另一人的响应 |
| G10 | 撤权后重放先前成功请求 | 拒绝业务结果，不能从幂等响应缓存绕过当前鉴权 |
| G11 | RUNNING 收到取消但数据库语句尚未停止 | CANCEL_REQUESTED，交付不可用，不伪报 CANCELLED |
| G12 | 完成与取消竞争 CAS | 只有先提交者赢；取消先提交则不得转 SUCCEEDED/交付 |
| G13 | SUCCEEDED 结果读取前撤权 | 执行状态保留；delivery 变 REVOKED，返回 403 |
| G14 | 隐私必要审计不可用 | 停止执行/交付，无无保护降级 |
| G15 | 仅修改 ViewSpec 且查询/范围/策略/水位条件仍匹配 | 新草稿版本可引用同一受控结果，不重复查询 |
| G16 | 只有颜色/小数位修改，之后已撤权 | 不得读取原结果；样式缓存不是数据授权 |
| G17 | 回滚到已退休/目录停用的旧版 | 拒绝回滚，不修改当前发布指针 |
| G18 | 有 APPROVE 但审核范围不符或作者自审 | 403，不发布 |
| G19 | 共享版本 DRAFT 使用私有保存事件绕过审核 | 拒绝；owner_saves_private_asset 只适用 PRIVATE ACL |
| G20 | 草稿确认后日期跨月或授权范围改变 | 409 ANALYTICS_CONFIRMATION_STALE，重新解释实际范围 |
| G21 | 运行 CANDIDATE 真实指标 | 422 ANALYTICS_CATALOG_NOT_APPROVED；不受 schema 合法性影响 |
| G22 | 同幂等键记录过期后重试运行/发布 | 通过持久命令 receipt 保持同一操作身份，不能仅依赖底座 24h 缓存 |
| G23 | 撤销/重做历史草稿 | 追加全新递增版本，保留旧内容；重新分类查询变化 |
| G24 | 安全停止本人任务但已无 RUN 权限 | 受信身份+同租户+所有权允许取消，不允许读取数据；他人任务需 MANAGE_EXECUTION |
| G25 | 资产整体 SUSPENDED，但客户端指定旧 PUBLISHED 版本 | 拒绝运行；所有版本受资产总停用约束 |
