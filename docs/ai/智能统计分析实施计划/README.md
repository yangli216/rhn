## 1. 如何使用

本计划将建设方案拆成 **4 个阶段、31 个工作包**。每个工作包有明确输入依赖、交付物、正反验收用例和不做的范围，适合作为 AI 下一轮的完整任务上下文。

“可独立验证”指：前置契约具备后，任务可使用固定合成事实、替身外部依赖和明确期望结果验证自身能力，不必等整个产品完成；它不意味着任务之间没有依赖。数据库方言、真实取消、模型效果和容量结论必须在相应真实环境验证，不能由替身结果推断。

默认按 A01 → A26 顺序推进，A27–A31 按业务需要选择。编号是建议顺序，具体就绪状态以每张任务卡的前置依赖为准。每轮先读取本总览、[任务状态表](任务状态表.md)、对应任务卡及当前仓库指令，完成后更新状态和证据，再建议下一项。未经用户要求不自动提交或推送 Git。

## 2. 推进规则与完成定义

### 2.1 一轮只完成一个可验收目标

每轮只处理一个工作包及其必要修复。发现相邻问题记录为后续项，不顺手扩大成其他工作包。任务包不是固定工时承诺；涉及多个独立交付面的 A10、A18、A19、A24、A26、A30 等，若预计无法在单轮完整验证，应先拆成 `A10.1 / A10.2` 等子任务，分别列依赖和验收标准并更新状态表。

拆分必须保留父任务的完整验收：例如 A10 可分 Oracle、PostgreSQL 和一致性复核；A19 可分全量导入、增量投影和交接/重放；A26 可分安全回归、模型评测、联合压测和试点决策。一个方言通过不能把父任务标记完成。

除非用户另行授权，本计划不要求并行 AI 代理或创建新 Codex 任务。依赖表用于判断顺序和阻塞范围。

### 2.2 每轮必须可审阅、可重跑

1. 明确所依据的目录、契约、策略版本和固定样例；期望结果来自独立手算/业务基准，不能用被测实现生成预期值。
2. 交付实际文件与最小完整行为；未完成的能力通过开关关闭，不能让前端提前访问无保护执行路径。
3. 根据修改范围运行必要的单元、接口、迁移、架构或交互检查。正向成功之外必须验证任务卡中的负向和边界用例。
4. 保存实际验证步骤、环境、结果及必要截图/报告，并更新状态表。模拟成功、未执行、执行失败必须区分。
5. 说明仍待院方决定或基础设施提供的事项；这些事项只阻塞依赖它们的真实接入或能力，不阻塞可用合成数据完成的开发工作。
6. 涉及运行交付时检查人工验证服务并提供验证入口。本次仅编写 Markdown 计划，不属于功能运行验收。

本轮文档检查不需要新增应用测试。实施时也不要为了勾选清单编写重复实现的测试；优先验证统计结果、越权拒绝、状态迁移、资源回收等真实行为。

### 2.3 开发通过与上线准入分别记录

- **开发验证通过**：合成数据、替身和适用的隔离测试通过，改动可审阅；外部准入缺失时状态写为“开发验证通过·准入待验”。
- **完成**：任务卡的独立验收以及适用业务/真实环境准入都有证据。文档类任务可以先完成“候选方案整理”，但不能冒称指标签字、医院审批或供应商承诺已经完成。
- **阶段放行**：明确列出已通过任务、尚未启用能力、临时裁剪与风险接受人。裁剪语音或导出可形成更小试点版本，不能宣称原方案该阶段全量交付。

## 4. 全阶段固定约束

- 只走“受约束分析定义 → 确定性计划/SQL → 受保护结果”；模型没有数据库账号、自由 SQL 执行、权限修改或发布批准能力。
- 真实执行、异步结果读取、缓存命中和下载都以当前运行者重新鉴权；共享的是模板，不能继承作者权限。所有关系分支先限租户/范围再聚合。
- 初次口径和计算规则变化需要明确确认；纯样式变更即时预览并可撤销；结果绑定版本，旧结果不能覆盖新草稿。
- 权限服务、策略和必要审计不可用时失败关闭。不得把撤权、隐私、取消、预算和审计推迟到 MVP 之后补做。
- PC 默认适配 1280–1920px+，三栏协作、中央预览为主，1280px 右栏可收起；不做手机专用单列布局。
- 数据归属和跨模块接口遵循现有模块边界；数据库迁移遵循 PostgreSQL/Oracle、Snowflake 与租户复合外键规范。接口变更同步 OpenAPI 和生成类型。
- 后端自动化测试使用隔离 `test` 配置与随机 H2；真实 Oracle/PostgreSQL 方言、取消及压测使用专用测试数据库和非项目端口，不使用人工 Oracle schema 做破坏性测试。
- 浏览器操作与 QA 使用 ego-browser/ego-lite。按仓库要求涉及前端改动时运行适用检查，完整门禁为 `frontend` 下 `npm run check`；后端基线为 `backend` 下 `mvn test`，执行前确认现有测试配置满足隔离约束。
- 功能交付供人工验证前，检查 `http://localhost:8080/actuator/health` 和 `http://localhost:5173`。不可达时按项目说明恢复；8080 只能用 `oracle-local`。不停止既有服务、不使用广泛进程终止；仅清理本轮自己启动的临时实例，结束浏览器任务空间不影响服务。
- 不自动 commit/push；不记录真实患者内容、音频、密码、密钥或完整业务结果到普通日志或计划文档。
