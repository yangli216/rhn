# V3：通用展示模板与动态分析页面

2026-09-14，替换 V2 的业务示例预制方式。当前入口采用业务无关的展示模板与服务端指标目录，AI 根据需求生成分析定义，页面根据定义渲染。

## 使用方式

1. 点击“新建统计分析”，选择统计列表、排行分析、趋势分析、分组对比或综合看板。
2. 只描述业务数据需求。新建状态不出现默认指标卡、默认查询表单或挂号图。
3. AI 从指标目录选择指标组合、分组、日期规则和统计范围，服务端验证后查询数据并预览页面。
4. 指标卡、图表数量与表格列由实际指标集合决定。模板固定页面组织方式，不固定业务指标。
5. 用户确认并固化到左侧功能库。重新打开自动取数，可以修改日期与范围运行；已有个人分析兼容读取。

可体验：

- 排行分析＋“本月门诊各诊断的有效确诊记录条数，查看前10项”。
- 综合看板＋“本月各科室的挂号人次和诊毕人次情况”。
- 统计列表＋“最近30天每日挂号人次和退号率”。
- 对“查看本月诊断数量排行”，AI 会询问是否按有效确诊记录条数统计，避免混淆记录数和去重人数。

## 动态定义与数据能力

新增 `/api/analytics/pages` 下的 catalog、generate、query、saved 接口。页面定义保存模板、1至4个指标、兼容分组、日期规则、权限范围和排行条数。AI 返回值须通过指标白名单、分组兼容性、模板约束及日期范围校验；不执行生成 SQL/HTML。

本轮目录包含挂号人次、挂号队列退号人次、诊毕人次、退号率及有效确诊记录数。新增指标仍需明确业务口径与数据接入，AI 不会自动访问全部业务表或虚构目录外指标。

诊断记录通过门诊领域聚合接口读取：按首次记录日期、机构时区，限当前权限范围内门诊本次就诊的当前有效且已确诊条目。排除已撤销、疑似、住院及非本次就诊阶段记录。主次诊断均计入，不按患者去重；诊断域、编码体系与编码共同确定分组。同一编码但未标注编码体系的旧记录单列，并在标签说明。

排行按数值降序、键稳定排序，支持前1至100项；指标总数统计全部分组。退号率总计按整体分子/分母重算，不累加分组百分比。权限范围由服务器解析，不接受任意科室ID。

本月、近30天、今年作为相对日期规则保存，每次打开按机构时区重新计算；也支持固定日期。AI 说明中的指标、范围和日期按最终有效定义生成，避免说明与查询不一致。
