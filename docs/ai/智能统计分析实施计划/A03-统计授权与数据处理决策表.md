## 1. 核心判定与现有能力边界

一次统计访问应同时满足以下条件，任意一项缺失都不能通过：

1. 当前有效身份和可信租户、合法工作上下文。
2. 在本次机构/科室作用域生效的动作权限。
3. 草稿、资产、运行结果或导出对象的租户及所有权/共享 ACL。
4. 当前数据集、指标、维度/字段、访问目的、机构和科室统计授权。
5. 目录审核状态、资源预算、聚合隐私、有效数据水位和必要审计。

**工作科室不等于统计授权集合；资产共享不等于共享数据；全院仅指明确指定的一家机构，不等于整个医共体租户。**

## 2. 开发默认值与授权范围解析

### 2.1 仅用于未批准前开发的默认值

| 能力 | 默认值 | 含义 |
| --- | --- | --- |
| 数据 | 仅合成；real_data_enabled=false | A02 所有指标仍 CANDIDATE，不因本轮场景设定变成正式批准 |
| 输出 | aggregate_only=true | 可设计聚合功能；真实聚合仍需权限与隐私通过 |
| 明细 / 导出 | detail_enabled=false / export_enabled=false | 即使合成用户有动作也拒绝启用，后续专项批准必须同时满足动作、范围、目的和字段策略 |
| 外部模型 / 语音 | external_model_enabled=false / speech_enabled=false | 替身模型和可编辑文本可继续；院内语音也要先批准实际路径 |
| 敏感群体策略未定 | 敏感维度和相关真实结果不开放 | 未经批准不随意猜一个阈值放行 |
| 留存策略未定 | 不接真实会话、结果快照和导出存储 | 合成文档按开发资产保留；生产时长不由本轮擅自确定 |

这里的名称是规格字段，**尚未新增配置或开关实现**，也不是医院已经采纳的制度。

### 2.2 范围解析规则

统计授权记录建议至少绑定：主体、租户、机构、科室集合、数据集版本、指标集合、允许维度、访问目的、敏感等级、有效期、策略版本、授予来源与撤销状态。机构和科室必须保存为合法归属元组，不对两个独立集合做笛卡尔积。

- 租户只来自受信执行上下文；所有数据/关联/比较期/下钻都先施加同一租户和有效范围，再做聚合。
- 当前工作机构限定本次操作上下文；用户要切换另一机构，应先通过该机构的工作上下文校验并重新解析统计授权。某机构的统计授权不得跨上下文自动生效。
- “当前授权范围”可在当前机构内展开统计授权科室，并展示实际范围。例如 D_A1 工作上下文可展开批准的 D_A1+D_A2，结果标注“部分科室”。
- 显式指定未授权科室、混合合法与非法科室、要求完整全院但授权不完整时，整体拒绝并允许用户改选授权范围；不悄悄缩小后仍回答“全院”。错误信息只说明授权不足，不枚举用户无权看到的组织/目录对象。
- “全院 H_A”只有在批准目录中该医院可统计科室集合完全被授权覆盖时才成立。新科室/组织合并不自动扩大原授予集合，更新需重新审批/解析并更新策略指纹。
- 无授权集合返回拒绝；有授权但确实无数据返回空结果，两者不能混同。
- 有效期使用 `[valid_from, valid_until)`；撤销/停用即时失效。统计授权变化更新范围指纹；已有缓存和结果清单不是授权凭证。
- 指标和派生指标都要获准。M12 基于 M07 不意味着有 M07 就能自动使用 M12；运行派生指标还需其获批依赖版本与策略允许，拒绝通过公式变相恢复被保护分子。

## 4. 动作权限与对象规则

拟议九项动作与建设方案保持一致，A04 冻结细节、A06/A08 随迁移和常量登记。本轮不声称权限编码已存在。

| 动作 | 可允许的操作 | 还必须检查什么 |
| --- | --- | --- |
| ANALYTICS.READ | 浏览授权目录、个人/共享定义，读取本人合法结果 | 对象 ACL、租户及实际结果当前权限；不能凭 READ 执行新查询 |
| ANALYTICS.CREATE | 新建/修改自己的草稿、保存个人资产、继续修改已共享模板的新草稿 | 所有权、基础版本、目录/字段白名单；不能修改他人或不可变发布版本 |
| ANALYTICS.RUN | 提交分析运行、参数化复用 | 指标/数据范围/目的、预算、隐私、审计；运行者权限 |
| ANALYTICS.EXPORT | 发起受控导出、读取合法导出状态 | 功能已批准启用、对象归属、独立额度；下载仍再次鉴权及凭证绑定 |
| ANALYTICS.DETAIL | 申请已批准数据集中的明细能力 | 专项目的审批、最小字段、敏感策略和时效；不是所有患者字段通行证 |
| ANALYTICS.PUBLISH_DEPARTMENT | 提交目标科室模板发布 | 目标科室发布授权、所有权、依赖有效性；提交不等于批准 |
| ANALYTICS.PUBLISH_ORGANIZATION | 提交指定机构模板发布 | 目标机构发布授权；不能将全租户误作全院 |
| ANALYTICS.APPROVE | 批准职责范围内发布申请 | 审核对象机构/科室与类型、自审限制、当前版本；审批不授予数据查询权 |
| ANALYTICS.MANAGE_CATALOG | 编辑职责范围内候选数据集/指标治理信息 | 目录对象管理范围、业务审批记录；不授予运行、患者查询或自主扩大权限 |

取消本人在途任务应允许安全停止，不以获取业务结果为前提；撤权后仍不交付结果。取消、资产停用/移交与审计查阅的精确动作映射由 A04 明确，不能用 MANAGE_CATALOG 统包所有运维权。

共享资产 AS_SHARED 属于 T_A/H_A、作者 U_HOSP；U_D1 可读取定义并按 D_A1 运行，实际范围必须显著显示。AS_PRIVATE 为 U_D1 个人草稿，U_MULTI 即使同科室也无权读取。所有 ID 查询，包括运行、导出、批注和版本历史，均执行对象级检查，统一不泄露不可访问对象是否存在。

## 5. 指标、字段、用途与聚合隐私

| 内容 | 普通统计默认 | 条件与拒绝边界 |
| --- | --- | --- |
| M01–M12 | 仅批准后可授权的聚合候选 | 未获业务审核、主体指标许可或依赖失效则拒绝；科室授权不能替代指标授权 |
| M13 / 复诊率 | 生产不支持 | MPI/复诊口径尚未治理，院级管理员也不例外 |
| 维度 | 候选机构/科室、时间、已治理来源/就诊类型 | 只能用目录白名单及作用域；类型 FOLLOW_UP 不自动成为复诊率 |
| 医生维度 | 关闭 | 等待 actor 与人员映射、历史归属和敏感策略 |
| 患者 ID、姓名、联系方式、病历正文 | 不向普通统计用户或模型提供 | 内部去重需单独数据集能力，不能把内部字段变成可选择输出字段 |
| 用途 | 仅合成 OPERATIONS_REVIEW | 应绑定授予记录；营销、科研或任意自然语言目的不自动获准 |
| 明细/导出 | 关闭 | 开启需 D03/D04 决定及专项策略，不通过图表批注绕过 |

敏感群体不是单凭“聚合”就安全。合成演示可以使用 `k=5`，但这不是医院已批准的阈值，也不是匿名化证明。

- 示例两组值为 3、9，总计 12。只隐藏 3 仍可由 12−9 恢复，因此合成预期至少同时隐藏该小组与可恢复它的总计；也可采用经批准的合并分组等方案。
- 所有指标卡、表格、图表、tooltip、分子分母、比较差额、辅助摘要、缓存和导出使用同一受保护出口，不在隐去的单元格底层保留原值供前端读取。
- 多次邻近筛选、总计/细分查询、相邻日期与重复下钻可能联合恢复小群体，需要跨查询的风险记录、维度/频率限制和审查；单次 `k` 检查不够。
- 新旧授权、数据水位和目录策略必须进入结果指纹。跨范围/跨策略结果不能混用，即使看起来都是同一张图。
- 正式敏感分类、零值处理、最小群体阈值、次级抑制和差分限制由 D05 决定；未定前敏感真实查询保持关闭。A02 的原始小数值只能用于离线统计正确性验证。

## 6. 模型、语音与结果的数据路径

| 数据 / 阶段 | 可设计的数据路径 | 未批准前行为 | 必要准入证据 |
| --- | --- | --- | --- |
| 用户原始文本/批注 | 应用接收，先按敏感输入规则处理，再送批准模型 | 仅合成文本/替身；不将真实原文发外部 | 输入脱敏/阻断规则、目的、模型处理位置与协议 |
| 语义目录 | 服务端先过滤为有权业务名称/类型/版本 | 可用合成目录；不发完整物理库表 | 指标授权、字段最小化、提示注入防护 |
| 语音原始音频 | 已批准院内转写端点优先；转写为可编辑文本后用户确认 | 语音关闭、保留文本入口 | 真实网络提交目标、轮询/结果路径、网关日志及供应商保留/训练用途证据 |
| 转写文本 | 与普通文本相同地校验敏感性，再进入需求理解 | 未确认不触发统计查询 | 识别错误更正、转写和后续模型两条独立处理路径均获准 |
| 查询计划/SQL | 服务端确定性编译、只读批准数据对象 | 仅合成设计与离线验证 | A08–A13；不让模型获得数据库账号、SQL 执行或任意网络工具 |
| 聚合结果/辅助摘要 | 先做保护，再向获准消费者交付；摘要数字从保护后结果绑定 | 仅合成预期；不发原始患者行 | 模型是否允许接收聚合结果需另定；抑制值不能由摘要恢复 |
| 下载 | 审批后由受控结果存储→本人短时下载凭证 | 导出关闭 | 用户/租户绑定、当前鉴权、到期删除、水印、公式注入防护 |

禁止“先把音频发公网，再把转写文本脱敏”作为音频保护措施。临床网关不持久化音频仅约束应用，服务商任务缓存、日志、训练使用、备份和实际路由需要独立确认。院内/外部路径均按实际请求目的地审查，不以模型品牌或标签代替部署证据。

## 7. 撤权、结果交付与故障处理

| 检查时点 | 必须重新核验 | 失败时行为 |
| --- | --- | --- |
| 提交/排队前 | 身份、动作、对象、目录、范围、目的 | 拒绝新任务，记录受保护的拒绝事件 |
| 实际执行前 | 上述权限、时效和策略版本 | 不使用任务消息里的旧授权快照，取消或拒绝 |
| 执行中 | 撤权/停用通知或交付前兜底复核 | 请求真实语句取消；取消失败也不能交付，记录取消失败告警 |
| 取结果前 | 当前权限是否仍覆盖结果的范围/指标与隐私策略 | 拒绝旧结果；不得先交付全院结果再隐藏列。需缩小范围时重新运行 |
| 缓存命中 | 当前权限与完整指纹、水位、策略版本 | 不返回过期或不匹配缓存；不得绕过必要审计 |
| 下载前 | 当前身份/对象/导出权限、有效范围及凭证用户/租户/期限 | 拒绝；已合法下载的副本不能声称能远程收回 |
| 审核/发布时 | 当前审核职责、对象范围及依赖版本 | 不批准过期、越范围或已变更版本 |

权限服务、策略解析或必要审计不可用时停止执行和交付；模型不可用时可使用已批准的确定性报表和参数表单。二者不能采用相同的“无保护降级”。

## 8. 审批职责和留存待定边界

候选职责分离：作者提交、业务负责人确认口径、范围匹配的发布审核人批准；敏感数据、范围扩大、资源增加时增加相应安全/资源审批。合成策略禁止作者自审，允许审核人只读清理后的定义而无业务结果权限；实际组织是否采用这些职责由 D08 确认。

| 对象 | 建议可访问者 | 未批准前约束 / 待定留存 |
| --- | --- | --- |
| 原始音频 | 仅获准转写处理端 | 应用不持久化；供应商任务与日志保留须确认；录音失败/取消也处理内存和临时缓冲生命周期 |
| 原始文本、批注和草稿 | 作者及明确授权的治理人员 | 可能含患者信息，不随模板发布；生产 TTL、删改与备份删除待 D09 |
| 已发布模板 | ACL 范围内使用者/审核人 | 仅共享审核定义、说明、参数与版本；对话、原始结果和敏感批注不共享 |
| 运行结果、缓存、受控快照 | 当前合法运行者或获批数据产品消费者 | 持续重鉴权；生产 TTL、加密、到期清理及历史复现责任待 D09 |
| 导出临时文件和下载凭证 | 发起者本人 | 独立短期生命周期，成功/失败/取消均清理；具体时长未擅定 |
| 必要审计与受保护参数引用 | 独立获授审计职责人员 | 追加、防篡改、访问审计、受限加密参数；普通日志不含敏感原话、结果、音频或密钥 |

不把“没有确定留存天数”解释成永久保留，也不未经批准删除正式审计。生产数据持久化在 D09 决策前不开放；合成 JSON 和文档可按开发资产保留。
