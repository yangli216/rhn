# 决策模型目录匹配试用

本轮在 `rhn-intelligence` 内建立独立 Choice 决策模型适配器，目前接入辅诊建议的“已有治疗意图 → 院内目录项目”和智能建方的“检查检验意图 → 系统可识别项目”。不生成新治疗意图、不判断适应证、不参与处方安全门禁。病历生成继续使用现有 LLM。

## 配置与试用

1. 系统设置 → AI 助理配置中心 → 当前租户覆盖 → 决策公共配置。
2. 模型默认 `jev-1.13.0`，地址默认 `https://api.typesafe.ai/v1/systemone`；填写独立 Jev API Key。密钥沿用 AES-GCM 存储及配置管理权限，不继承 LLM 密钥。
3. 点击“测试 Jev 连接”。这一步可以测试未保存的地址、模型及密钥，只发送虚构的 CBC 目录匹配题；成功只说明连接及接口有效，不代表中文医学准确率。
4. 在“决策业务场景”选择需要试用的场景：辅诊建议默认开启场景开关（保留原有试用行为），智能建方默认关闭。总开关默认关闭；模型、密钥、超时、置信度只配置一份，所有已开启场景共用。总开关选择“旁路观察”，保存变更。AI 主运行模式须为“模型辅助”，当前医生必须在原有机构、科室与医生灰度启用范围内。
5. 门诊医生站 → 智医助理 → 生成含治疗项目的建议。已有名称或编码唯一精确匹配直接走确定性逻辑；只有模糊候选触发 Jev。因此使用目录别名、同名多规格或检查组合等模糊意图才能观察试用。
6. 展开智医助理的“接诊摘要”（或建议中的安全提示区）可见“目录决策试用”，含模型版本、耗时及追踪号。旁路仍显示原有 LLM 推荐；日志 `catalog_decision_comparison` 用相同追踪号记录 Jev 与 LLM 项目 ID。相同不代表正确，应由医生核对。
7. 完成旁路核对后，可切换“辅助匹配”。每个意图选择一个等价项目或 NONE；所有判断达到门槛才采用本次 Jev 匹配结果，否则整批回退原有 LLM。达到门槛的 NONE 保持未匹配，不强行选择。
8. 总开关切换“关闭所有场景”并保存即可恢复所有场景的原有匹配流程；也可单独关闭某一业务场景。

## 智能建方试用

1. 填写共享 Jev 配置，开启“智能建方”场景；总开关先选旁路观察。
2. 在 AI 智能建方中确认方案叙述、检查检验候选后执行转换。编码、标准名称或机构本地名称唯一精确匹配直接采用目录；模糊名称与多个同名候选才调用 Jev。
3. 例如目录本地名称为“血常规”，输入“血常规检查”可通过去检查后缀召回，再交给 Jev 判断。候选由当前机构可开立目录提供，继续受类型、有效期、采纳状态和有效售价约束。未召回候选仍需人工检索。
4. 旁路模式在核对任务详情中展示模型选择，但不新增对应系统项目。辅助模式仅在整批达到门槛且返回候选内 ID 时生成可识别项目；NONE、低置信度、超时和非法 ID 保留人工核对。多项检查检验意图批量调用一次。
5. 药品剂量、频次、包装及诊断转换继续使用现有确定性逻辑。转换后仍由医生核对并保存整体方案。

新增决策场景时，在 `DecisionScene` 注册业务键、说明和默认开关，并通过迁移添加对应布尔参数；调用方指定场景，不另建模型或密钥配置。

建议用虚构就诊样例验证：名称别名、多规格歧义、院内无等价项目、Jev 地址不可达。请对照院内实际目录选择样例，不能保证任意一句输入都有模糊候选。精确匹配及没有目录候选时不产生额外调用。

## 运行边界

- 只发送意图名称、类型、代码、规格及候选目录描述；不发送患者标识、病历、原始问题、建议理由和历史记录。
- 候选最多 64 个；原始候选超限时不在被截断的候选集上做 Jev 决策，回退现有流程。
- 每个意图独立 Choice，均含 NONE。保留原始分布及 provider confidence；置信度门槛默认 90%，仅表示分布集中程度，未在本地校准，不代表临床正确率。
- 默认关闭，配置即时读取。旁路会增加一次有界调用延迟（默认最多等待 8 秒）；不保证和关闭时延迟相同。
- 没有密钥、HTTP 错误、超时、无效概率/未知 ID、低置信度均提示回退。任何目录推荐仍需医生确认，开立时继续执行目录、库存及安全校验。
- 日志 `catalog_decision` 保存业务场景、租户、追踪号、输入指纹、题目版本、实际模型版本、模式、时延和候选概率；不记录请求正文或密钥。日志由现有服务日志生命周期管理，本轮不新增持久化评测表。
- 调用方复用既有门诊推荐与采纳流程；无需增加 Maven 模块，不迁移药师人工审方或合理用药规则运行时。

## 验证范围

自动测试覆盖配置默认关闭、密钥加密与热加载、非法配置拒绝、原生 HTTP 协议、概率/候选校验、关闭/旁路/辅助/NONE/回退、保留确定性匹配、前端独立密钥连接测试以及架构门禁。真实 Jev 推理和浏览器流程由用户填写密钥后验收。
