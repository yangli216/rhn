# 真实 AI 首轮验证：重复用药与相互作用

2026-09-21。使用本机已配置的 `qwen3.8-27b`，通过现有模型适配器实际调用。输入为已核对的公开摘录、项目验收策略和合成业务需求；数据库使用 `test` 配置及随机 H2。没有创建真实患者或启用临床规则。隔离环境仅替换配置解析和身份上下文；模型 HTTP 调用、抽取校验、标准候选查询与存储使用正式实现，没有预设模型返回。

## 发现与修正

首轮模型能识别药品和相互作用类型，却漏填原文已明确的配对关系与临床意义。已调整抽取提示：完整保留 A/B 配对、共享关系的“或”列表及忠实的中文意义摘要；未提供的年龄、途径、风险等级和系统动作仍保持待明确。

同时明确来源区别：说明书、法规中的业务设计附注不能冒充原文；机构策略草案已经明确的规则可以整理，但仍属于待确认策略。知识来源选项新增“法规 / 规章”，避免把法规标为临床指南。

## 验证范围

| 输入 | 验收重点 |
| --- | --- |
| 《处方管理办法》的重复给药审查要求 | 能识别重复用药；不擅自补出“两条”、同一处方、不限年龄或系统阻断 |
| DailyMed 克拉霉素说明书摘录 | 提取配对关系和临床意义，保留原文各药名；“合用”不改成“同一处方”，禁忌不自动映射为系统 BLOCK |
| 重复用药＋相互作用的组合需求 | 分别识别两类意图，保留肾功能条件、分次开立例外及待澄清项 |
| 说明书摘录＋明确标注的验收设计 | 不把验收设计的年龄、规格、同处方范围和提醒动作当成说明书规定 |
| 待确认的重复开立机构策略 | 整理策略明示的同标准条目、两条医嘱和同处方范围，保留草案来源，不编造风险分级 |

结果：最终五组真实调用的 25 项检查全部通过；实际抽取提示为 `RHN-QMED-KNOWLEDGE-EXTRACTION-V2`。同批知识模型与抽取回归共 16 项测试通过（含真实调用测试），前端相关 12 项通过，前后端打包通过。

机构策略样例的途径引用被模型截成“及途径的有效医嘱”，缺少“不限”的完整表达，系统没有填入不限途径。该项仍需药师补充或重新抽取，不能把检查通过解释为草稿已完整。

## 仍需人工完成的部分

这组验证检查模型在上述材料上的整理能力，不能证明所有说明书、所有表述或多次调用都正确。药名候选仍需核对标准条目、剂型和规格；未得到候选的英文名称需人工匹配。年龄、途径、实际用药时间重叠以及机构控制动作，不能用模型常识补齐。

模型整理结果仅能填入未保存草稿。来源核对、临床结论、适用范围和启用策略仍由业务审核确认；本次结果不代表这些临床规则已经批准。
