# 标准基础数据恢复说明（2026-09-22）

本轮针对 Oracle 数据库重建后标准关联丢失的问题，重新核对当前 2209 条启用药品，并把可重复恢复的结果固化为受控清单和幂等脚本。恢复范围聚焦合理用药运行依赖的药品身份、剂型、规格、制剂单位及结构化含量，不扩展版本管理、审计报表等外围能力。

1958 条关联均通过运行时的药品类型、剂型、规格、制剂单位、盐型限定和目录身份校验。其中包括重建后已恢复的 1370 条、本轮修正宽泛剂型后新增的 545 条，以及规格符号归一、特殊剂型限定和重复档案治理后新增的 43 条。剂型修正只处理恰好存在一个候选、且除剂型外身份字段完全一致的记录；12 条与新剂型明确冲突的默认途径和频次同步清空。头孢曲松、维生素 B1、沙丁胺醇、连花清瘟、左氨氯地平和正清风痛宁等代表性档案均已覆盖。正清风痛宁已按目录拆分为缓释片 60mg、普通片 20mg 和肠溶片 20mg，保留完整的“每片含盐酸青藤碱”规格原文。

本轮恢复后，278 条关联具备明确浓度语义，1055 条仍明确标记为临床换算不可用。不可计算状态不会用默认值补齐，也不会影响药品身份关联本身。

## 固化资产

- `标准药品关联基线-2026-09-22.json`：以药品编码和标准规格 ID 保存 1958 条已核对关联，同时冻结目录 ID、版本和内容哈希。
- `标准目录待核对清单-2026-09-22.csv`：保留本轮治理前 294 条缺口快照，用于复核处理依据。
- `scripts/restore-medication-standard-baseline.mjs`：默认只核对差异；增加 `--apply` 后，先修复 10 条已有明确依据的历史主档，再自动修正清单中唯一的纯剂型差异，并通过业务 API 幂等恢复关联。
- `scripts/reconcile-medication-dose-forms.mjs`：识别唯一的纯剂型差异，默认只预览；增加 `--apply` 后修正主档、重新校验并建立关联。
- `scripts/export-medication-standard-baseline.mjs`：从当前运行时导出所有有效关联并稳定排序，避免手工维护基线。
- `退役历史药品清单-2026-09-23.json` 与 `scripts/quarantine-unresolved-medications.mjs`：固定治理 247 条无安全标准身份且无产品依赖的历史记录。

执行方式：

```bash
node scripts/restore-medication-standard-baseline.mjs
node scripts/restore-medication-standard-baseline.mjs --apply
node scripts/reconcile-medication-dose-forms.mjs
node scripts/reconcile-medication-dose-forms.mjs --apply
node scripts/export-medication-standard-baseline.mjs
node scripts/quarantine-unresolved-medications.mjs
node scripts/quarantine-unresolved-medications.mjs --apply
```

脚本会先比较标准目录 ID、版本和内容哈希。目录发生变化时立即停止，不能把旧关联静默迁移到新目录。已关联相同规格的记录跳过；已关联其他规格、候选不再满足身份校验或药品编码不存在时，分别输出冲突、不可关联或缺失状态。

## 专业边界

当前标准目录的官方通知和附件存在性已经核对，但目录条目来自项目内 Word 转录，来源审核状态仍是 `UNVERIFIED`。因此，本轮结果可以作为系统开箱运行的药品身份基础，不能替代第二药师对全部转录规格、真实厂家说明书和临床阈值的复核。

无法证明唯一标准身份的记录没有自动套用近似项。247 条无产品依赖的历史拆分或不完整记录已退役；流感疫苗、美罗培南、青霉素效价单位和黄芪饮片 4 条机构样例仍需真实说明书或药典来源，不能为追求覆盖率推断补齐。

合理用药规则可直接依赖已关联记录的标准身份、结构化规格和换算能力。重复用药与相互作用规则还需继续补齐成分关系、证据来源、适用人群、给药途径和严重度；本轮没有自动发布新的强制拦截规则。
