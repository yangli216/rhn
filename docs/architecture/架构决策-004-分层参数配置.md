# 架构决策-004：当前值参数模型、可控继承与一致性缓存

- 状态：已采纳
- 日期：2026-08-26

## 背景

系统参数和业务参数会被门诊、药事、收费、公卫、家医、接口和管理端共同使用。若每个模块自行设计默认值、机构覆盖、父级查找和缓存，会出现不一致的优先级、跨租户读取、旧缓存和无法解释最终值来源等问题。

业务已明确本阶段不建设参数审批、发布、业务版本、计划生效和自动回滚。因此，原有“定义 + 发布修订”模型收敛为“定义当前状态 + 作用域当前值 + 追加式变更日志”，避免为简单场景保留两套权威状态。

## 决策

`platform.configuration` 独占参数分类、定义、当前值、变更记录和解析缓存。业务模块只依赖 `platform.configuration.api.ConfigurationDirectory`，不能查询参数表或自行实现继承与缓存。

权威模型固定为四张表：

- `parameter_categories`：管理界面分类树，采用乐观锁；
- `parameter_definitions`：参数定义当前状态，采用乐观锁；
- `parameter_values`：参数在规范作用域中的唯一当前值，采用乐观锁；
- `parameter_changes`：定义和值每次变化的前后快照，只追加不修改。

参数定义包含稳定参数键、名称、说明、值类型、界面控件、JSON Schema、默认值、示例、单位、字典绑定、允许作用域、系统/业务属性、继承与缓存开关、空值策略、敏感级别、展示策略和启停状态。参数键创建后不可修改或复用；已有当前值后不可修改值类型。

## 作用域和值模式

作用域统一为 `PLATFORM`、`TENANT`、`ORGANIZATION`、`DEPARTMENT`、`USER`、`PRODUCT`、`MODULE`、`ENVIRONMENT`。后端根据受校验的上下文生成 `scope_code`，前端不能任意填写最终作用域编码。

当前值使用四种明确模式：

- `OVERRIDE`：当前作用域提供覆盖值；
- `INHERIT`：当前记录存在，但继续向更宽作用域查找；
- `RESET_DEFAULT`：在当前作用域明确恢复定义默认值并停止查找；
- `EXPLICIT_NULL`：在允许空值时明确返回空并停止查找。

停用代替物理删除。人工回退将历史快照恢复为新的当前值，并追加 `ROLLBACK` 日志，不删除或改写历史记录。

## 解析顺序

启用继承时，从请求上下文按以下顺序查找，遇到第一个非 `INHERIT` 的启用当前值即停止：

```text
用户
  → 当前科室 → 父科室 → ...
  → 当前机构 → 父机构 → ...
  → 租户
  → 模块 → 产品 → 环境
  → 平台
  → 参数定义默认值
```

同类型父级优先于下一种作用域。附加的模块、产品和环境上下文位于租户之后、平台之前，且只在请求传入相应编码且定义允许该作用域时参与解析。

关闭继承时，只查询请求上下文中定义允许的最具体作用域，不查父节点、其他层级和定义默认值。未维护精确值时返回 `PARAMETER_VALUE_NOT_FOUND`。

解析结果返回请求作用域、实际来源作用域、规范作用域编码、值模式、修订号和 `inherited`，便于业务日志和问题排查解释最终来源。

## 事务、幂等与租户约束

- 定义和值更新必须提交 `expectedRevision`；并发冲突不允许最后写入覆盖。
- 当前状态更新和 `parameter_changes` 追加必须在同一事务完成。
- 每个管理写命令提交全局唯一 `requestCode`；重放同一命令返回原结果，跨定义复用同一编码返回冲突。
- 平台值没有租户归属；其他作用域值必须属于当前租户。
- 用户、机构和科室标识必须通过 IAM/组织公开 API 校验；科室同时校验所属机构。
- 机构、科室和分类树遍历检测循环并限制最大 64 层。
- 管理查询只返回平台值和当前租户值，跨租户值按不可见处理。

正式管理端必须由 IAM 策略限制定义、平台值和租户值的管理权限。当前认证适配层仍属于开发底座，不能把“已登录”视为生产授权策略。

## 缓存策略

当前值解析使用 Caffeine 进程内缓存。缓存键完整包含租户、用户、机构、科室、产品、模块、环境和参数键，避免不同上下文共享结果。

- 只有定义启用 `cacheEnabled` 时写入缓存；
- 定义、值、启停或回退事务提交后统一清空参数缓存；
- 缓存最大容量和 TTL 由环境配置控制，默认 10,000 条、5 分钟；
- 返回的 JSON 节点进行防御性复制，调用方不能修改缓存内容；
- 多实例部署前必须在同一失效入口接入 Redis Pub/Sub、消息总线或等价的跨节点通知。

## 敏感数据边界

- 普通和敏感参数可以保存 JSON 值，展示策略可为明文、掩码或隐藏；
- `SECRET` 参数只能保存外部密钥服务引用，不能保存默认明文、实际明文或明文快照；
- 密钥引用不是密钥访问授权，业务仍需通过密钥服务执行身份鉴别、授权和访问审计；
- 参数不能替代强类型业务事实、权限策略、临床规则版本或审计记录；
- 金额、处方、医保、库存等关键行为应在业务事实中记录最终解析值或来源修订，满足事后解释。

## 后果

后续业务只调用一个解析入口即可获得稳定、可解释的多级覆盖结果，管理端也只有一套当前权威状态。代价是本模型不提供计划发布和历史时点重放；未来若出现已验证的审批、灰度或历史重放需求，应以新的模型版本扩展，不能把当前变更日志伪装为业务版本。
