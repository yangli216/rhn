# 机构项目管理需求边界

## 目标

区域平台统一维护中心基础数据，各医疗机构在中心目录范围内建立本机构可用目录，不复制中心主档，不允许机构直接修改中心数据。

## 功能边界

### 基础数据中心

- 维护区域共用的疾病术语、诊疗项目、药品知识、药品产品、包装、标准映射和扩展属性定义。
- 仅具有 `MASTER_DATA.MANAGE` 权限的系统或区域管理员可以新增、修改、停用和批量导入中心数据。
- 不维护机构本地编码、机构显示名称、机构业务能力和机构价格。

### 机构项目管理

- 机构从中心目录调入诊疗项目和药品产品，不允许创建中心目录之外的机构项目。
- 机构可以维护本地编码、本地名称、默认科室、有效期和允许开放的业务能力。
- 诊疗项目能力包括开立、执行和收费；药品产品能力包括开立、收费、采购、库存、发放和退回。
- 机构可以维护本机构价格。药品产品支持按包装或最小单位计价。
- 机构可以共享另一个机构的目录。本机构显式配置优先于共享配置，本机构暂停配置可以屏蔽共享项目。
- 共享关系仅允许一层，禁止自引用和链式共享；价格不从来源机构继承。
- 机构用户只能维护当前工作机构的数据。跨机构维护仅允许具有 `MASTER_DATA.MANAGE` 权限的管理员执行。

## 权限

| 权限 | 范围 |
| --- | --- |
| `MASTER_DATA.ACCESS` | 查询中心基础数据 |
| `MASTER_DATA.MANAGE` | 维护中心基础数据和跨机构管理 |
| `ORG_CATALOG.ACCESS` | 访问当前机构项目目录 |
| `ORG_CATALOG.MANAGE` | 调入、覆盖、屏蔽、定价和设置共享来源 |

## 验收口径

- 基础数据中心不出现机构项目调入、机构目录状态和机构价格操作。
- 机构项目管理使用服务端分页查询中心目录。
- 未调入项目可以单项或批量调入；已调入或共享项目可以建立本地配置版本。
- 机构级配置和价格变更保留版本历史，不直接覆盖历史记录。
- 没有中心维护权限的账号调用中心写接口返回 `403`。
- 机构账号维护其他机构目录或共享来源返回 `403`。
