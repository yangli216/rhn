# 新增字典弹窗走查

- 范围：字典管理 → 新建字典
- 目标：桌面端采用宽屏紧凑布局，减少滚动；窄屏保持可读和可操作。
- 证据：`01-before.png`、`02-after-desktop.png`、`03-after-narrow.png`、`04-comparison.png`

## 走查步骤

1. 打开“新增字典”：优化前弹窗为 528 × 860，桌面端需要滚动且底部操作区被截断；优化后为 832 × 562，完整表单一屏可见。状态：通过。
2. 检查新建初始值：优化前错误复用当前所选字典；优化后文本字段为空，并保留合理的作用域与分类默认值。状态：通过。
3. 检查字段层级：名称/编码、范围/分类、用途/原因按任务关系分成三行，长编码和分类获得更大宽度。状态：通过。
4. 空表单提交：名称和编码显示明确错误，弹窗保持打开。状态：通过。
5. 720 × 900 窄屏：字段回流为单列，无水平溢出，底部操作仍可到达。状态：通过。

## 结论与限制

桌面比例、信息层级、创建状态隔离、必填校验和响应式回流均达到本轮目标。截图可确认布局、可读性和可见状态；屏幕阅读器朗读顺序与浏览器缩放 200% 仍需独立辅助技术测试，不能仅凭截图宣称完整无障碍合规。
