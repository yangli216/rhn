# 标准药品目录业务链路联调

按当前约定，先贯通业务链路，暂不增加数据核验、药学审核或发布审批流程；药品内容由使用者在调试中维护。标准来源的待核验标记作为参考信息，不阻止建立本院药品。

## 操作入口

进入基础数据中心 → 药品目录 → 标准参考目录，搜索药品，点击“查看”，在具体剂型规格下点击“建立本院药品”。

1. 药品属性：自动带入名称、剂型、原始规格、明确的制剂单位及可映射的单方含量。补充制剂单位即可继续；默认剂量、途径和频次可以暂时留空。复方、浓度等不会强行压成一个单方含量。
2. 厂家产品：选择生产厂家，填写产品编码、包装单位、包装系数和采购/零售价格，保存时一并建立产品、包装、本机构启用配置和两类价格。
3. 保存完成后自动切到“产品信息视角”，定位刚建立的药品。药品默认用法从“基本信息视角 → 编辑主档”维护；厂家和包装从“产品信息视角”维护；机构启用及价格从“机构项目管理”维护。
4. 在库房管理中配置该产品的库存货品和期初入库，随后可使用现有门诊医生站、收费和药房流程调试。

范围条目没有具体药品规格，因此不提供建档按钮；尚未拆出规格的条目可通过原有“新增药品”手工建档。不存在额外的核验或审批前置条件。

## 复用与保存

同一标准规格使用 `STD-*` 编码建立通用药品。再次从该规格进入时，读取并维护已有药品，再进入厂家产品配置，不重复建立通用药品。已有产品也不会被覆盖，可在原产品入口修改。

第一步与第二步分别保存：取消产品配置不会删除已建立的药品；产品保存失败时保留表单，可以直接重试。第二步的产品、包装、机构采纳和价格由现有事务一次保存，失败时整体回滚。保存期间阻止重复提交。

参考目录本身仍为只读快照，独立于本院可编辑药品。后续修改本院名称、规格或用法，不会自动回写或覆盖来源文件。本次没有新增在线版本管理或审核流程。
