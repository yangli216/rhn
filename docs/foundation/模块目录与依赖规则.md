# 系统模块目录与依赖规则

## 模块目录

| 模块 | 责任 | 拥有的数据 | 可依赖 |
|---|---|---|---|
| `shared` | 稳定技术原语、错误契约、分页、事件信封 | 无业务表 | 无业务模块 |
| `platform.tenant` | 当前租户执行上下文 | 无主数据表 | `shared` |
| `platform.organization` | 租户、机构树、科室树、从业人员、聘用、岗位与任职 | `tenants`、`organizations`、`departments`、机构/科室档案组件、`practitioners`、`employments`、`positions`、`staff_assignments` | `shared`、`platform.tenant` |
| `platform.dictionary` | 管理平台/租户普通枚举字典的当前定义、当前字典项和追加式变更日志 | `dictionary_definitions`、`dictionary_items`、`dictionary_changes` | `shared`、`platform.tenant` |
| `platform.terminology` | 按[字典与术语命名规范](字典与术语命名规范.md)管理编码体系、疾病等标准概念、别名、机构采用、值域、映射与版本 | `code_systems`、`concepts`、`concept_aliases`、`organization_concepts`、`value_sets`、`value_set_members`、`concept_mappings` | `shared`、`platform.tenant`、`platform.dictionary.api` |
| `platform.masterdata` | 管理诊疗项目、药品知识、生产企业、药品产品、包装、机构目录采用和有效期价格 | `catalog_items`、`item_aliases`、`service_items`、`medications`、`manufacturers`、`medication_products`、`item_packages`、`organization_catalog_items`、`catalog_prices` | `shared`、`platform.tenant`、字典与组织公开 API |
| `platform.configuration` | 参数分类、系统/业务参数当前定义、多级作用域当前值、父级继承、变更留痕和缓存 | `parameter_categories`、`parameter_definitions`、`parameter_values`、`parameter_changes` | `shared`、`platform.tenant`、组织/IAM/字典公开 API |
| `platform.eventing` | 领域事件记录、事务 Outbox、进程内投影通知 | `outbox_events` | `shared`、`platform.tenant` |
| `platform.cryptography` | 关键数据完整性/不可否认证据、策略门禁与密码服务适配 | `cryptographic_evidence` | `shared`、执行上下文；对外只暴露 `api` |
| `platform.printing` | 打印模板解析、不可变 PDF 输出、生成与重打审计 | `print_templates`、`print_template_versions`、`print_outputs`、`print_jobs` | `shared`、`platform.tenant`；对外只暴露 `api` |
| `platform.integration` | 外部消息幂等、负载摘要、收发状态、业务关联和交换队列 | `external_messages` | `shared`、`platform.tenant`；对外只暴露 `api` |
| `healthcore.mpi` | 统一居民身份和来源治理 | `residents` 及 MPI 相关表 | 仅平台公开 API |
| `healthcore.clinicaldocument` | 临床文档、不可变版本、签署、修订、归档与正式打印编排 | `clinical_documents`、`clinical_document_versions` | `healthcore.api`、平台公开 API |
| `healthcore.timeline` | 居民健康事件查询投影 | `health_events` | `healthcore.api`、`platform.eventing.api` |
| `outpatient.encounter` | 门诊就诊状态和临床采集 | `encounters`、`encounter_diagnoses` | `healthcore.api`、平台公开 API |
| `outpatient.ordering` | 门诊诊疗请求、处方组、通用名/产品药品请求、换算快照、状态轨迹与处方打印编排 | `request_groups`、`care_requests`、`service_requests`、`medication_requests` | `outpatient.api`、`platform.masterdata.api`、`platform.printing.api`、组织与事件公开 API |
| `diagnostics` | 检查检验申请交换编排、回执、追加式报告版本和结构化观察结果 | `diagnostic_reports`、`observations`、`diagnostic_report_results` | `outpatient.api`、`platform.integration.api`、`platform.eventing.api` |
| `application` | 组装、启动和环境配置 | 无业务表 | 所有模块公开入口 |

## 强制依赖规则

1. 跨模块只能依赖目标模块的 `api` 包。
2. Controller 不能直接访问 Repository。
3. 一个模块不能修改另一个模块拥有的表。
4. `shared` 不得出现 Resident、Encounter、Medication、Charge 等业务概念。
5. 查询投影可订阅事件，但不能反向成为命令侧事实来源。
6. 模块新增依赖必须更新本目录并通过架构测试。
7. 是否拆为独立 Maven 模块由编译隔离收益决定，不改变上述逻辑边界。

## 字典与参数依赖边界

| 使用场景 | 允许依赖 | 禁止依赖 |
|---|---|---|
| 获取普通字典当前可选项或历史显示文本 | `platform.dictionary.api.DictionaryDirectory` | 字典 Repository、表和管理 Service |
| 获取代码封闭枚举目录 | `platform.dictionary.api.SystemEnumDirectory` | 字典模块 `domain` 枚举或前端硬编码中文映射 |
| 为响应字段绑定字典翻译 | `platform.dictionary.api.DictionaryBinding` | 手写 `sdXxxText` 或逐行查询字典 |
| 解析当前上下文参数 | `platform.configuration.api.ConfigurationDirectory`、`ConfigurationValue` | 参数 Repository、表、管理 Service、自建继承或缓存 |

管理 Controller、管理请求和管理响应不是跨模块运行时契约。业务模块的 application 层负责调用上述公开 API 并转换为本域的强类型值，domain 层不得依赖平台实现细节。完整接入方式见[字典与参数接入指南](字典与参数接入指南.md)。

## 模块内部结构

新模块统一使用：

```text
api/             对其他模块公开的契约
application/     用例编排和事务边界
domain/          实体、值对象、状态机和领域规则
infrastructure/  数据库、外部接口和框架实现
web/             HTTP 请求与响应适配
```

存量模块在 Foundation 1.0 期间逐步迁移，不做一次性机械改名。
