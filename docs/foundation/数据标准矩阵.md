# 医疗系统数据标准矩阵

编码体系、概念、值域和映射的登记键、归属与发布门禁统一见[字典与术语命名规范](字典与术语命名规范.md)。

## 标准分层

| 层级 | 内容 | 产品处理方式 |
|---|---|---|
| 国家/行业标准 | WS/T 数据元、值域、电子病历数据集、疾病和操作编码 | 作为标准概念和数据元来源 |
| 省市标准 | 区域平台、医保、公卫、疾控和电子健康卡接口 | 独立适配包和映射版本 |
| 产品标准 | RHN 内部稳定 ID、领域实体、事件和接口契约 | 主代码库统一维护 |
| 机构本地标准 | 科室、人员、药品、项目、历史码 | 映射到产品或上级标准，不污染核心模型 |

## 首批数据元责任

| 数据域 | 内部主标识 | 外部标识/术语 | 首批约束 |
|---|---|---|---|
| 租户 | Snowflake BIGINT | 客户代码 | API 中 ID 为字符串；代码唯一且不可复用 |
| 组织 | Snowflake BIGINT | 机构代码、本地科室码、组织分类 | API 中 ID 为字符串；机构、院区、科室共用组织树，按类别和类型区分 |
| 从业人员 | Snowflake BIGINT | 人员编码、执业标识 | API 中 ID 为字符串；与账号、聘用、任职分离 |
| 聘用/任职 | Snowflake BIGINT | 聘用号、任职号、岗位和专业编码 | 使用有效期表达历史；同一时点的主关系受领域约束 |
| 居民 | Snowflake BIGINT | 身份证、医保码、健康卡、病案号 | API 中 ID 为字符串；一个居民可有多个标识 |
| 性别 | Concept ID | WS/T 值域或产品兼容码 | 禁止自由文本 |
| 诊断 | Concept ID | ICD-10/国家临床版/本地码 | 保存编码体系和版本 |
| 生命体征 | Observation ID | 标准数据元、单位体系 | 数值、单位、时间和来源完整 |
| 配置 | Definition Key + Revision ID | 无 | 类型、作用域、有效期明确 |
| 领域事件 | Event ID | Event Type + Version | 全局唯一、不可变、可幂等 |

## 术语版本原则

1. 业务记录保存概念稳定 ID，同时保留当时的编码、显示名和版本快照。
2. 值域发布后不可原地修改成员语义，使用新版本和生效日期。
3. 本地编码通过 Mapping 关联标准概念，不直接覆盖标准概念。
4. 未映射、本地暂用和已停用概念必须可区分。
5. 历史记录按发生时版本解释，新版本不得改变历史含义。
