# 医疗系统核心领域词汇表

| 术语 | 定义 | 明确不等同于 |
|---|---|---|
| 租户 Tenant | 一个独立配置和数据边界内的县域医共体或产品客户 | 单家医疗机构 |
| 组织 Organization | 医疗机构主体主档，可形成机构层级并承载主体资格和对外治理信息 | 租户、科室、服务位置 |
| 机构 Legal Organization | 可以建立聘用关系的医疗机构主体 | 科室、租户 |
| 科室 Department | 隶属于一个机构、可形成独立科室层级的内部业务主档 | 机构、前端菜单、角色、诊室或床位 |
| 从业人员 Practitioner | 与机构关系无关的自然人主档，可跨机构存在多段聘用 | 登录账号、某次任职 |
| 聘用 Employment | 从业人员在一定有效期内与法定机构的劳动或聘用关系 | 科室任职、登录账号 |
| 岗位 Position | 可复用的标准职责模板，如全科医生、护士或药师 | 某个人、角色权限 |
| 任职 Assignment | 某段聘用下，人员在一定有效期内与机构、科室和岗位的工作关系 | 永久角色、聘用关系 |
| 服务位置 Location | 诊室、物理病区、床位组、药房窗口等提供服务的物理或逻辑位置 | 机构或科室主档 |
| 居民 Person/Resident | 被县域健康体系识别和服务的自然人主身份 | 某机构病案号 |
| 居民标识 Identifier | 身份证、医保码、健康卡、机构病案号等可追踪标识 | 居民内部 ID |
| 来源记录 Source Record | 外部或历史系统提供的居民原始记录 | 统一主记录 |
| 就诊 Encounter | 居民与医疗机构为一次服务发生的业务上下文 | 整段慢病管理周期 |
| 临床文档 Clinical Document | 经书写、审核、签署和归档管理的正式医疗记录 | 任意页面表单 |
| 健康事件 Health Event | 已发生且可进入居民时间轴的医疗健康事实投影 | 业务命令或消息队列消息 |
| 领域事件 Domain Event | 领域状态变化后发布的版本化业务事实 | 数据库表变更通知 |
| 普通字典 Dictionary | 平台或租户作用域内只维护当前值、以追加日志追溯变化的轻量枚举集合 | 标准术语、主数据、参数或业务状态机 |
| 术语 Concept | 在特定编码体系中具有稳定语义的临床或管理概念 | 页面显示文本 |
| 值域 Value Set | 某业务语境在指定版本可使用的概念集合 | 无版本字典表 |
| 参数定义 Parameter Definition | 参数键、类型、控件、作用域与安全策略的当前权威定义 | 某作用域中的实际参数值 |
| 参数当前值 Parameter Value | 某参数在某规范作用域中唯一的当前值或继承/重置/显式空模式 | 可用于历史时点重放的业务版本 |
| 参数变更 Parameter Change | 定义或当前值一次不可覆盖的前后快照和操作证据 | 审批单、发布版本或自动回滚任务 |
| 照护计划 Care Plan | 面向居民健康目标组织的一组长期活动 | 单次门诊医嘱 |
| 任务 Task | 分配给个人或团队、可追踪完成状态的工作单元 | 通知消息 |

词汇发生歧义时，先更新本表和领域模型，再新增数据库字段或接口。
