# 医生站打印版式调研与验收（2026-10-03）

## 调研结论

医生站打印应按纸质文书类型排版。原默认病历、处方采用 A5 横向的小字表格，检查、检验和治疗申请单采用通用 A4 流式表格；信息密度和签署区不符合常见纸质单据的阅读习惯。本次改为黑白标题、清晰的患者信息区、各文书专属正文和签署区。

依据以下公开一手资料，不把某一家医院的纸张规格当成全国统一标准：

## 默认版式

| 文书 | 默认介质 | 正文和签署 |
| --- | --- | --- |
| 门诊病历 | A4 纵向，210×297mm，12mm 页边距 | 10.5pt 正文；主诉、现病史、既往史、过敏史、体检及辅助检查、诊断、处理意见、宣教复诊、结构化专科字段；医师及签署时间。 |
| 西药/中成药处方 | A5 纵向，148×210mm，10mm 页边距 | Rp；药名和规格同排、数量靠右、用法单列；医师、药品金额、审核、调配、核对、发药。五项常规测试药品可在一页呈现。 |
| 中药饮片处方 | A5 纵向，148×210mm，10mm 页边距 | 三列饮片名称及每味剂量；保留后下等特殊嘱托；只有来源一致时汇总剂数、途径、频次。十八味常规样例可在一页呈现。 |
| 检查、检验、治疗申请单 | A5 横向，210×148mm，10mm 页边距 | 开单科室和执行科室分开；临床诊断、病情摘要、申请目的、项目和数量、标本或检查类别、申请医师及执行签署区。 |

不缩小长内容来强塞一页；长病程和超长药品嘱托自动续页。连续页保留文书类型、姓名、业务单号及页码。纸面不输出数据库对象 ID、编辑批注或审计摘要。

所有临床内容来自正式业务快照。剂量、途径、频次、阴性病史、体重及费用不凭版式推测。医师姓名通过来源账户关联的人员档案解析；无法解析时留签署线，不把内部账户 ID 当姓名。展示姓名不等同于电子签章，本次未新增签章或特殊药品处方资质能力。

## 升级及兼容

- 新增 `RHN_OUTPATIENT_DOCUMENT_V2` 渲染协议，复用已嵌入的中文字体；机构 FLOW/CANVAS 模板及旧协议继续可渲染。
- H2/PostgreSQL 与 Oracle 的 `V1_99_0` 为五个未升级的平台 V1 默认模板发布 V2，不覆盖已发布 V1、不更改机构自定义模板。
- 已生成输出及重打仍使用原 PDF 字节，升级不会让历史文书版式发生变化。
- 不替换机构打印机配置。旧纸型绑定与新介质不匹配时，现有服务回退至浏览器 PDF；需要直连设备的机构应给对应纸型配置设备绑定。
- 本次针对常规门诊文书。麻醉、精神、急诊、儿科等特殊处方的纸色、专用标识及机构特定格式需按当地要求选择专门模板。

## 验证记录

使用隔离 `test` 配置及随机 H2 数据库运行打印相关单元、集成和架构检查；未使用手工验证 Oracle 库执行测试。

本次结果：后端 46 项检查、前端打印相关 10 项检查通过；最终分页微调后重新运行 12 项渲染检查并在独立源码副本中完成打包。8 份 PDF 共 11 页完成渲染检查，文本字符越过物理页面边界为 0。

- 渲染回归：常规病历、西药处方、十八味饮片、三类申请单；核对纸张尺寸、页数、关键内容和签署区。
- 长文回归：保留正文末尾；续页带患者标识；超长药品嘱托不留下只有抬头的空白首页。
- 数据真实性：按文书日期计算年龄；未记录的剂量、途径和频次不补默认值；不输出内部 ID 或批注。
- 受控打印：发布模板预览、正式输出、重打字节一致性、批量 PDF 和设备介质匹配。
- 迁移回归：五个 V2 默认版本存在，旧 V1 布局协议仍保留。
- 将测试生成的 PDF 渲染为 PNG 检查边界、换行及续页。样张均为虚构测试数据，不用于真实诊疗。

测试日志及样张保存在 `.runtime/verification/outpatient-print*`，不提交到代码仓库。按项目约定未进行真实系统浏览器 QA；实体打印机走纸、驱动缩放和实际纸张仍需现场核对。打印时宜使用与 PDF 相同的纸型及实际尺寸，避免驱动自动缩放改变字号。
