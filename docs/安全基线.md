# 系统安全与合规基线

当前仓库中的 HTTP Basic 仅用于本地纵向切片。试点环境接入统一身份平台前不得直接用于真实医疗数据。

正式环境最低要求：

- OIDC/OAuth2 身份认证、MFA 与统一人员身份；
- RBAC + 机构/科室/辖区/医患关系数据范围；
- 查询、修改、导出、打印和 AI 调用全量审计；
- 紧急访问需说明理由并进入事后复核；
- TLS、敏感字段保护、密钥托管和测试数据脱敏；
- 关键数据使用统一密码证据底座完成完整性保护；人员签署绑定个人证书和可信时间，生产禁止使用开发签名提供者；
- 外部接口签名、时效校验、幂等与防重放；
- 数据备份、恢复演练、漏洞和依赖治理；
- 医疗数据不得被默认发送到外部模型。

在接入真实居民数据前，必须完成数据分类分级、个人信息保护影响评估、安全测试和试点机构制度确认。

密码保护架构、生产准入条件和业务接入目录分别见 [ADR-003](architecture/架构决策-003-密码证据.md) 与 [关键数据密码保护目录](foundation/关键数据密码保护目录.md)。底座就绪不等于通过密评，最终以密码应用方案和测评结果为准。
